# v0.1.2 发布说明

0.1.0 之后的一次整理版：改掉与别人重名的包名，补上「没答完的问题」这条线（含关闭），把记忆图谱从设置页里搬出来做成独立页，并在侧栏给了入口。

## 改名

- 仓库、npm 包名、插件 id、路由前缀、数据目录统一为 **`dsh-perch`**（旧名 `dsh-roost`）。
- 新仓库：<https://github.com/bychance6600/dsh-perch>；旧地址自动重定向。
- **数据目录会自己搬**：第一次在新名下启动时，若 `~/.dsh-perch` 不存在而 `~/.dsh-roost` 存在，直接 rename 过去；搬不动就继续用旧的，不会因此起不来。
- 升级兼容：`lib/upgrade.js` 同时认 `dsh-roost`、`dsh-roost-core`、`dsh-perch-core` 三个旧包名，老 profile 不改也能升。
- 路由前缀从 `/dsh-roost/*` 变成 `/dsh-perch/*`；记忆页新地址 `/dsh-perch/memory`。

## 没答完的问题（openq）

- 新事件类型 `openq` / `openq-close`（schema 已加）。
- 识别只扫她自己说的话（`source === 'system'` 的 utterance），窄正则三族；同一句 24 小时内去重，每天最多 2 条。
- 摆的时候只摆事实，不派活：「你说过一句：…」「这句还没有下文。」「相关的：11-08 你搜过「撒娇」。」
- 材料只从 7 天内的 `searched:` / `looked:` 里取，词面重合才带，最多一条；没有就不硬凑。
- 今天页单独一节「没答完的」，最多 3 条。
- **新工具 `openq_close`**：她可以给一个问题收尾——`resolved`（答上了）或 `dropped`（不打算再答），可附一句 ≤60 字的说明。关闭后不再摆；今天页只列开着的，关掉的在侧栏「最近关掉的」留一行。

## 设置页

- 首屏只等 3 条请求，其余 25 条按页签补（`load()` / `loadRest()`）。首屏从约 282KB 降到 43KB，体感从 1.3s 降到 0.45s 量级。

## 记忆图谱

- 独立页 `/dsh-perch/memory`，不占设置页；侧栏新增「记忆图谱」一行，点开就是这张图。
- 伪 3D：按深度排序、近大远小、可左键旋转 / 右键平移 / 滚轮缩放 / 双击归位。
- 三种颜色模式：状态（判断/改口/被推翻/疤）、分组、时间。
- 筛选直接作用在点上：点图例只留该类、点组标签只看该组、再点恢复；「只看被引用过」「最近 N 天」「搜原话」；工具条最左「全部」一键清空。
- 节点带 `status`，被推翻的判断之间是真的红边（不再只靠 `tensions`）。
