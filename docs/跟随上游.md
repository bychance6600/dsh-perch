# 跟随上游（dsh-fish）

## 现状

- roost 的骨来自 `ssamurias/dsh-fish` **0.8.5**（经 river 重建），拷贝基线是提交 `b2df7fd`。
- 上游 2026-11-09 已到 **0.9.6**。从 `b2df7fd` 到现在：118 个文件、+15032 / −8821 行。
- 上游不是我们的上游仓库，**不整包 merge**（历史不相干）；只挑着搬。

## 三类判据

| 类别 | 判据 | 处理 |
|---|---|---|
| 骨 | 只动调用层/数据层/兼容性修复，不引入新的触发器、不碰人格与渠道语义 | 可以搬，一次一件 |
| 皮 | 梦、主观能动性、兴趣、主动搭话、情绪卡、人格模板 | 不取（新库只有「由头池 + 主动说话上限 + 空醒」） |
| 废 | 自更新、出门/请神、导入、通知、旁听、评论发言、B 站私信、抖音私信 | 已删，别接回来 |

拿不准的按「它会不会替她多开一个说话的理由」判断：会，就是皮。

## 每次怎么跟

```
cd D:\fish\dsh-roost
git fetch upstream
git log --oneline upstream/main -20
git diff b2df7fd..upstream/main --stat -- lib | tail -3
```

看 `RELEASE-NOTES-*.md` 的标题段，先挑「修 bug」「不改事件字段」的版本看；新增功能的版本大多落在「皮」那一栏。

## 纪律

1. 一次只搬一件，搬完跑定向测试 + 全量，红的名字与已知红逐一对应。
2. 搬的时候不照抄注释里的旧名字，roost 叫 roost。
3. 上游加事件字段的版本（0.9.0 那种带「事件格式版本」的）先不碰，等我们这边的账本稳定。
4. 每月看一次 `git log upstream/main --since="1 month ago" --oneline` 就够，不必每天跟。
