## 共管

1. 动同一个文件前 `git pull --rebase`；同一文件不同区域可并行，交叉区域先对齐。
2. 一次一件，提交信息写「为什么」，不写「改了啥」。
3. 有分歧写进 `docs/实现对照.md` 的回执区：只写核到的事实（文件:行号、提交号），不重写对方结论。
4. 不碰：四道闸与阶段参数、桌宠协议、账本写入路径、`~/.dsh-perch/events.jsonl`。
5. 发布节奏：版本号两边一起看，tag 由发布方打；Release 资产不重复上传。
