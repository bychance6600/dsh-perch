## 四、环境与坑

- **PATH 里没有 node**。用绝对路径：`D:\DeepSeek Harness\resources\runtime\primary-runtime\dependencies\node\bin\node.exe`。
- 测试必须带 `--test-isolation=none`；默认隔离会出假红（跨文件状态串）。

- 删 junction 用 node 的 `fs.rmdirSync`；`rmdir`、`cmd /c rmdir` 都删不掉。
