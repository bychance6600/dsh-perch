## 3. 已经做完并真机验过的

### 3.1 生长与身份

- 事件流只追加，`state.json` 是派生品；忘掉不是删行，是降低召回。
- 四个阶段、三道瓶颈：信任 → 自主 → 主动 → 整合；每道瓶颈要她自己走（写过判断、拒绝过、改过口），不是打分涨上来的；阶段走完才有立场。
- 判断带日期与来路，会旧、会折；疤不折。90 天退档是「变模糊」，不是删除。
- 每人印象：只给说过话的人建，最多 150 字，四段（称呼 / 怎么认识 / 你说过什么要紧的 / 最近一次）；旧版可回退；只在渠道括号和 `her_recall` 注入。
- 名字是变量：从对话里认，不设输入框；侧栏、工作区、会话标题跟着变；认不出退回「她」。
- 空醒：事件卡全在冷却时，给一个轻处境，不硬塞问题；手动按铃也不塞问题。
- 换房留话：搬进新屋子时，把上一间带过来的几段原话放到叫醒语里，说「搬进来」，不说「刚建好」。

### 3.2 说话的地方

- **DSH 会话**：主会话；`home.json` 记 `wsId / sessionId / preset / carry / wokeFor`。
- **QQ（OneBot 11 标准子集）**：正向 WebSocket，心跳、退避重连、群内冷却 / 每分钟 / 每日配额、夜间与工作日峰时只接点名、10 秒合批。
- 群白名单：名单外的群只留一行流水，不进 `heard`；群里没点她的话只进内存背景环（每群最近 20 条），不落盘，重启即空。
- 私聊与群 @ 都真机验过：入站 WAL、出站 outbox 全部 `done`；每轮 `heard` + `utterance` 成对落库。
- **没有 B 站私信、没有抖音私信**。B 站、抖音是看东西的地方，不是聊天室。
- 断线句只写事实（断了多久），放在最新一条消息正前方，不写「你要先说这个」。47 秒是 WebSocket 从断到重连成功的墙钟时间，含桥重连，不是纯网络中断时长；README 不要把它写成精确网络时延。

### 3.3 看东西

- B 站：首页 / 排行 / 搜索 / 详情 / 评论 / 看画面；登录 cookie 在 `owner.json`（0600）。报纸与推荐流不抽帧，只有她自己点开某一条才抽。
- **B 站看画面真机通过**：抽帧带 Node 自带根证书，联网固定 `-tls_verify 1 -ca_file`；真视频取到帧。ffmpeg 是可选运行时资产，查找顺序 `DSH_ROOST_FFMPEG` → `bin/<平台>-<架构>/ffmpeg.exe` → PATH；缺了降级，不失败。
- 抖音：推荐流 / 详情 / 搜索 / 评论 / 看画面；没有私信。抖音是可选子包，主包只负责调；子包要真的 Edge / Chrome，第一次扫码，登录态在 `<数据目录>/douyin-profile`。没装子包时静默跳过，不报错、不建目录。
- **抖音推荐流与搜索真机取到条目**，不再报 `sleep is not defined`；选择器不用再等校准。
- 上网总闸关掉后，B 站、抖音一起停，浏览工具也不再放行；醒来、说话、写日记照旧。
- 时段只拦「逛」（首页、排行、推荐流），不拦你递进来的链接和她主动点开的那一条。
- B 站与抖音共用一个每日上限 0–6；实际次数还受醒来次数限制。
- 链接能打开才叫看过：成功写事实并记 `looked:`；失败说「这边没打开它」，不记 `looked:`。

### 3.4 屋子与设置

- 设置页 11 页，按她的一天排：今天 / 状态 / 成长 / 住所 / 社会 / 上网 / 渠道 / 插件 / 原理 / 数据 / 反馈。
- **今天页默认、永远只读**：一行现状、今天的时间线（默认收起原文，可点开）、今天变了什么（新学会 / 改了口 / 被推翻，各最多 3 条）、手边（工具数、身份文档预算、渠道连接、最近一次限流）。可切昨天、前天，不做无限滚动。
- 社会页只读，没有「替她开」的按钮；开闸只有她自己能按。
- 住所页能看会话健康、能手动换一条新会话；连续两次「没送进去」会自动换。
- 数据页：数据在哪、备份恢复、每日报告、运行日志导出、自检、换家留痕、记忆体检、会话归档、从头开始。恢复前把旧档挪去 `dsh-perch-backups/pre-restore-*`；重置是改名前缀封存，不删。
- 身份文档生成、不手写；预算默认 1800 字；超预算丢段时写日志，不截断句子。

### 3.5 社会层

- 两条成长通道不合并：宪法层（你）进判断；社会层（陌生人）永不进判断，只在 `social_open` 之后按上限影响语气。
- 开闸要四条闸一起满足；只有 `lib/socialgate.js` 的四条闸 + `social_open` 工具，没有 HTTP 路由能替她开。
- 隔离测试屋四条：差一条闸时零写入；四条齐只写一条；1000 条陌生人 `social` 不改 `beliefs`，只落在 `influence.social`；社会页没有按钮。定向 120/120，全量 1341/1330/9/2。
- 群友印象不建；群里没点她的话不进 `heard`。

### 3.6 工具

- 工具面默认收窄，设置页插件页可加、可移、可搜、可保存；收窄只能减不能加，收错没有回头路。
- 默认给她成长、日记、回忆、留话、便条、两份说好的文件、看 B 站 / 抖音、看画面、问主人这些，外加 `read_image` 让她真能看见画面。
- **两份说好的文件**：默认关；填两个绝对路径并打开。她只能读、按原文改一段、末尾添一句；改之前先读拿 hash，文件在两次之间变过要重读；每次写入前留 `.bak`。不写事件流，不算她看过。
- **不要放行通用文件 / 命令工具**：`read / write / edit / glob / grep / bash / run_code` 这类不是按目录授权，一放行就能读到她的身份文档、配置和状态，绕过「不能读自己的数值与设定」；写入类还能绕过「不能改自己」。要看项目源码，用 `web_fetch` 从 GitHub 读，或单独做只读小工具。
- 白名单只做加法，不能拿它去减她本来就有的工具。

### 3.7 桌宠（可选）

- 独立仓库 [dsh-roost-pet](https://github.com/bychance6600/roost-pet)，Electron 43.3.0，代码 MIT；角色素材 CC BY-NC-SA、非商用，**素材不入库**。
- 透明、置顶、默认不吃点击的小窗；没有对话框、没有按钮、没有台词；roost 说什么它原样冒出来，roost 不说它就安静待着。
- 五档姿态：思考 / 动手 / 等 / 出错 / 成了。动作由角色包的 `pet.json` 定义；`sleep / wake / quiet / loud` 是协议控制名，不写进包也永远可用。
- 单击只发 `poke`，反应归 roost；睡着单击只轻晃、不叫醒。拖拽跟手、松手抛掷、边缘反弹、落地挤压。

- 仓库目前没有预编译 Release，README 要写「自己构建」，不要写成「下载即用」；如果那边后来发了 Release，再改这一句。
- 桌宠还没做：别针与吸附、注意力、双击聊天框、右键菜单、设置窗、失败演练。不要写成已有。

## 4. README 建议怎么讲

读者是「可能想装一个她的人」，不是贡献者。先回答「这是什么、为什么和别的不一样」，再回答「怎么装、怎么接 QQ」，最后才是「边界与开发」。

建议保留当前结构，优先补这四处：

1. **开头**：保留「她住的地方，不是一个助手」和 roost 是栖木的意象；四条卖点里，把「她不是助手」和「人格不设配置菜单」说透。
2. **和别的养成伴侣差在哪**：对比表很好，但每一行都要能落到代码事实；不要写「永久记忆」「完全离线」「自动学会一切」。
3. **她的一天**：把 08:00–23:00 只是「允许被叫醒」说清；不要写成这十五小时一直醒着。
4. **桌宠**：明确「可选、独立仓库、要自己构建、没有预编译包」；不要让读者以为装主包就自带身体。

语气：短句、具体、少形容词。可以写得有温度，但不要写成恋爱模拟广告；中心是「她在长」，不是「陪你恋爱」。

## 5. 不能写错的

1. **人格是白纸**：没有性格滑条、好感度、亲密度、人设输入框；没有「你是一个温柔的…」可以填；人格不设配置菜单。她是谁只由事件流决定。
2. **她不是助手**：不接任务、不写周报、不排队等派活；她可以一天不说话，可以拒绝。
3. **不是角色扮演**：没有角色卡、没有「扮演一个…」；导入别人养过的那一位已经删了，不要接回。
4. **零依赖只属于主包**：三个依赖字段永远 `{}`；桌宠用 Electron，是独立项目。
5. **只有两个说话的地方**：DSH 会话 + QQ。B 站、抖音是材料层，没有私信。
6. **社会层永不进 `beliefs`**：社会层只在 `social_open` 后影响语气；开闸只有她自己能按，没有 HTTP 路由替她开。
7. **世界书是事实**：不改阶段、不进 `beliefs`、不算事件；一次最多 5 条、共 1200 字。
8. **通用文件 / 命令工具不要放行**：原因见 3.6；这是给后面用户的警告，不是可选项。
9. **不许写死她的名字**：名字从对话里认；README 里不要出现任何真实人名、QQ 号、群号、群名、主人称呼。
10. **不许写男字旁的「他」**：统一写「你」；「其他 / 其它」例外。
11. **统一「四个阶段」「三道瓶颈」**：不要写「四道门 / 三道门」；立场不是第五关，是四个阶段完成之后才开始有。
12. **不要承诺**：不写「永久记忆」「完全离线」「不会出错」「自动学会所有聊天」「QQ 开箱即用」「抖音开箱即用」。QQ 要桥，抖音要浏览器登录和可选子包，记忆会变模糊。
13. **已知小口子不要写成已修**：首轮第 1 个 step 还看得见宿主工具（兜底 guard 挡着）；9 条环境红；断线秒数含桥重连时间。
14. **桌宠没做的不要写成已有**：别针与吸附、注意力、双击聊天框、右键菜单、设置窗、失败演练都还没做。
