# v0.1.3 发布说明

v0.1.2 之后的一次小版本：加了「把旧对话搬进来」这一件事，并把 npm 包名真正发出去（0.1.2 在 npm 上被误删，需等 24 小时冷却，故从 0.1.3 起算）。

## 迁移旧对话（新）

`tools/import.mjs`，三种来源：

- DSH 工作区会话（`session.v4.jsonl.zstd`，多帧 zstd 逐帧解）；
- SillyTavern 导出的 `.jsonl`；
- 纯文本 `.txt`（一行一句）。

只搬**那个人说过的话**，写成 `heard`（`source: system`）。她说过的话一条不读——那些是在别人的人设提示词下生成的。人设卡、`core.md`、`topics/*.md`、记忆结论、好感度数字一律不碰。

- 默认干跑，`--write` 才写；
- 先写 `meta import-mark:<来源>:<条数>` 留痕；
- 时间等比例压到导入前的一天内，阶段与「认识多久」从今天重新算；
- 第一次叫醒时用一句话说明来历（「从别处搬来的旧对话，不是在这里发生的」），只说一次；
- 宿主注入的运行时上下文、系统提醒、压缩摘要会被滤掉；「他给别的 AI 下的指令」分不出来，干跑时看样例。

用法与边界见 `docs/迁移指南.md`；规矩写在 `AGENTS.md` §2 的唯一窄例外里。
