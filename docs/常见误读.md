# 常见误读：外部描述核对

这份文档核的是「外部对 roost 的描述」：每条只写三件事——外面怎么说、代码实际怎么做、依据在哪。行号以当前 HEAD `a0e79ca` 为准；事件数是 2026-11-10 本机快照。

## 一、养成与记忆

| 说法 | 实际 | 依据 |
|---|---|---|
| 四个阶段靠证据升级。 | 一半对。阶段取日历时序与证据瓶颈的较小值：`stage = Math.min(elapsedStage, gateStage)`。三段证据瓶颈只拦第 1–3 段：trust 至少 1 条判断；autonomy 拒绝至少 2 次；competence 的改口 + 纠正 + 让步（让步最多算 1）至少 2。第 4 段没有瓶颈。三段都过后按日历走：默认 30 天，第 9 / 17 / 27 天进入下一段（`stageBounds` 返回 8 / 16 / 26 / 30）。时间兜底不是「每阶段各 30 天」：`stageSpanDays` 是总预算，默认 30 天；总预算走完后的下一天，未过的瓶颈一次性标 `forced`，不会永久卡死。 | `lib/derive.js:21-22`（权重与顺序）、`:197-223`（阶段边界）、`:903-935`（`stage = min(...)` 与 `forced`）、`:973-986`（三道瓶颈的判定）。 |
| 反复提起就固化。 | 不完整。反复提起只是条件之一：`mentions >= 3` 或 `verified >= 2`（`SOLID_MENTIONS = 3`、`SOLID_VERIFIED = 2`）。固化后还有保质期：满 90 天且不是疤，会 `faded`，排序退一档、不再进 `solid`；仍留在 `beliefs` 里，原文仍在 `events.jsonl`，`her_recall` 仍翻得到。 | `lib/derive.js:171-189`（门槛与 90 天）、`:749-760`（`weathered` / `faded` / `solid`）、`:762-769`（排序）；`lib/recall.js:100-113`（`solid` 用于召回加权）。 |
| 记忆 90 天衰减。 | 只对已经固化的判断生效，条件是 `weathered && ageDays >= 90 && !scarred`。它不是删除：`faded` 只是降一档，判断还在 `beliefs`，原文一直留在事件流；疤不退档。 | `lib/derive.js:179-189`（注释与 `FADE_DAYS = 90`）、`:755-760`（`faded` 条件）；`lib/recall.js:150-176`（仍可按字面翻到）。 |

## 二、常见质疑的判定

| 说法 | 实际 | 依据 |
|---|---|---|
| 事件流只增不减。 | 真。`events.jsonl` 只有 `appendFile`，没有 update / delete；`state.json` 是派生快照，删掉可以用 `rebuild()` 从事件流重建。启动和每次唤醒都全量读 + `deriveSelf`，没有增量索引。截至 2026-11-10 本机 2,565 条有效事件（1,147,446 字节，`readEvents` 8.6ms），`deriveSelf` 连续 7 次 169.4–199.5ms（约 170–200ms）；「2,483 条、十几毫秒」是旧数。冷归档未做。 | `lib/store.js:1-12`（只追加、state 是快照）、`:129-161`（全量读）、`:168-203`（唯一写入口）、`:224-242`（`rebuild`）；`lib/index.js:165,219`；`lib/scheduler.js:276,312`；实测命令 `node D:\fish\_archive\measure-derive.mjs`（仓库外临时脚本）。 |
| 摘要是有损压缩。 | 部分真。折行只发生在自述 / 身份文档那一层：更早的判断折成一行，睡眠自述是摘要。判断本身保存事件里的原话（`said`），事件流不因摘要丢原文，`her_recall` 能翻回。 | `lib/persona.js:82-110`（`BELIEF_SHOWN` / `BELIEF_FOLDED` / `foldOlderBeliefs`，注释写明「压缩，不是删除」）、`:522-578`（睡眠自述，不用定时摘要器）；`lib/selfdoc.js:95,188`；`lib/derive.js:414-437,456-476`（判断存 `said`）。 |
| 零依赖等于放弃向量检索。 | 真。三个依赖表全空；检索是切词 + `String.includes`，没有向量 / embedding。换个说法召不回，是这个选择的直接代价。记忆图的软边按字符 bigram Dice ≥ 0.34 连边（最多 900 条），展示的是词面相近，不是语义检索。 | `package.json:82-84`（三个依赖表为空）；`lib/recall.js:64-78`（切词）、`:150-157`（字面命中）；`lib/memory-page.js:169,201-219`（Dice 与 0.34 阈值、900 上限）。 |
| 人格是黑盒，难定位。 | 不成立。`deriveSelf` 是纯函数：不写盘、不缓存、不读环境变量，同样输入同样输出（`now` 除外）。每条判断的 id 就是来源事件 id，改口用 `refs` 指回旧 id；`state.json` 删掉后可以从事件流重建并对比。难的是人读几千条事件，不是机器定位。 | `lib/derive.js:1-8`（纯函数铁律）、`:342-346`（`deriveSelf`）、`:434-437`（判断 id 取事件 id）、`:456-476`（`refs` 与旧句状态）；`lib/store.js:224-242`（重建快照）。 |
| 不可逆。 | 事件本身不可改删：`capture.js` 明写只增不改，存储层只有 append。但她有出口：`revise` 改口 / 推翻并保留旧句，让步话（`CONCEDE_RE`）记进 `conceded`，疤可以被 `revise` 标 `resolvedAt`（疤本身不删），立场分「守的线 / 不做的 / 喜欢的」三类。`resetAll` 默认把整个状态库 rename 到备份目录，从空白开始；所以「技术上不能重置」不成立，「不原地抹掉」是产品选择。 | `lib/capture.js:8-10`；`lib/store.js:1-6,168-203`；`lib/derive.js:426-432`（让步）、`:456-476`（改口 / 推翻）、`:600-629`（`resolvedAt`）；`lib/stance.js:42-49,90-101`（三类）；`lib/reset.js:114-144`（rename 到备份目录）。 |
| 成长会卡关。 | 不成立，但时间兜底不是「每阶段 30 天」。瓶颈看的是一次性累计事实：判断至少 1 条、拒绝至少 2 次、改口 + 纠正 + 让步（让步最多算 1）至少 2。没过且总 `stageSpanDays`（默认 30 天）没走完，会停在原阶段；总预算走完后的下一天，未过的瓶颈一次性标 `forced`，阶段补到 4，所以不会永久卡死。 | `lib/derive.js:903-935`（`forced` 只在总预算走完后生效）、`:973-986`（三道瓶颈的累计事实）。 |

## 三、只剩两条真问题

1. **检索精度（同义词）**：现在只有字面切词，换个说法就可能召不回；缓解方向是同义词表，再考虑可选的本地小索引——**未做**。
2. **事件增长（一年后的重算成本）**：每次启动 / 唤醒都全量读 + `deriveSelf`，事件越多越慢；缓解方向是冷归档（按年切分，启动只读最近一段）或增量派生缓存——**未做**。
