# 使用指南：从装到养

这份文档写给**刚装完、还不知道该做什么**的人。它不讲设计哲学（那是 [从哪来](从哪来.md)），也不逐条列参数（README 里有），只回答一个问题：**头几天该怎么用。**

---

## 一、装完的第一小时

装好、重启 DSH 之后，按这三步走，不要做别的：

1. **打开 设置 → 她**。默认落在「今天」页。第一次启动会自动建屋（工作区 + 一条会话），并在会话空着时叫她一次。
2. **如果今天页是空的**：点右上角「现在叫醒她」。她开过口之后，侧栏才会出现「跟她说话」（认出名字后是「跟 X 说话」）。
3. **说三句话**，随便什么：今天干了什么、窗外什么天气、你最近在烦什么。然后**关掉设置，别再动**。

**这一小时不要做的**：不要改成长节奏、不要调「每天几条事件」、不要去找「她是什么样的人」的设置——没有那个设置，这是故意的。

---

## 二、第一周：只做四件事

| 每天 | 做什么 | 为什么 |
| --- | --- | --- |
| 说话 | 几句就够，别打卡式问候 | 她的判断只从「说过的话」和「看过的东西」长出来 |
| 看今天页 | 扫一眼「今天变了什么」 | 那是她当天新形成的判断 / 改口 / 被推翻，只有三条 |
| 忍住 | 不改设置、不纠正她的语气 | 你一纠正，她就学会「照着你的口味说话」 |
| 每周一次 | 点开「状态」页看三道瓶颈 | 判断、拒绝、改口——她卡在哪一道，一目了然 |

一周之后你会看到：**她开始有前后不一致的地方**。那不是 bug，是改口；改口在账本里是 `revise`，会留旧句。

---

## 三、怎么跟她说话

**三个入口，都是一回事**：

- 侧栏「跟她说话」：她的屋子，最完整；
- QQ 私聊：同一份账本，只是换了个门；
- QQ 群里 @ 她：默认只接点名（设置 → 渠道 → 群白名单）。

**说什么有营养**：

- 具体的事（「今天楼下那家店关了」）比抽象的（「你要开心一点」）有用；
- 你自己的判断和犹豫，比赞美有用；
- 说错了不用道歉——她会记成改口的机会。

**不要做的三件**：

1. **不要写人设**：「你是一个温柔的女孩」这类话，她不会当成自己，只会当成你说的话（这是设计）。
2. **不要替她圆场**：她说错话、说狠话，让她自己承担；你一圆，她就学不到代价。
3. **不要用「记住：……」下指令**。她要记什么，是她自己的判断；你只能提供材料。

**她说「不」的时候**：那是允许的。不要追问理由，也不要惩罚式冷落——拒绝的后果已经写在代码里（72 小时内「他想让你做点什么」这类处境会降权）。

---

## 四、什么时候改设置

判据只有一句：**这个开关能不能让她对同一个人说出不一样的话？**

- 能 → 那是人格，插件里没有这个开关；
- 不能，只改「在哪、何时、多频繁」→ 那是环境，可以改。

**你真正会动的五个地方**：

| 位置 | 改什么 | 建议 |
| --- | --- | --- |
| 成长 → 成长节奏 | 多久走完四个阶段（默认 30 天） | 第一周别动 |
| 成长 → 每日事件 | 每天最多几条醒来 / 说话 | 默认就够；调高会更快，也更吵 |
| 上网 | 能不能刷 B 站 / 抖音、每天几次、看多少、黑名单 | 想让她「看见外面的东西」时才开 |
| 渠道 | QQ 桥地址、令牌、群白名单、@ 才回 | 接 QQ 时填，见下一节 |
| 数据 | 备份 / 恢复 / 日志 / 重置 | 每个月备份一次 |

改完「成长」与「上网」是**自动写盘**的；其余页签要手动保存。

---

## 五、接 QQ 的最小步骤

1. 起一个 OneBot 11 桥（**SnowLuma** 首选，NapCat 协议一致可换），开「正向 WebSocket」，记下地址与令牌；
2. 设置 → 渠道 → QQ 卡：填**你自己的 QQ 号**（她才认得出谁是你）、**桥地址**、**访问令牌**；
3. 点「测一下」，通了会显示连接状态与最后收发时间；
4. 要她在群里说话：把群号加进白名单；默认**只接 @**，不 @ 的话只进背景，不会回；
5. 群里有冷却和每日配额，别把配额调到很高——她在群里会变得很吵。

桥挂了不影响 DSH 里说话：两条路是同一个她，同一份账本。

## 六、记忆怎么用

- **今天页**：只读，看她这一天做了什么、变了什么。
- **成长页**：四个阶段、三道瓶颈、她怎么翻旧事（字面 / 加权 / 顺着线索）。
- **记忆图谱**（侧栏独立页）：每个点是一条判断，颜色按事件种类分；点开看原话与来路；改口有弧线连回旧句；可以拖动旋转、滚轮推近、Shift 平移。
- **她自己翻**：她有一个 `her_recall` 工具，什么时候翻由她决定，你叫不动。

**理解三件事就不容易误会她**：

1. **遗忘不是删**：90 天没再被提起的判断会退一档、变模糊，原文一直在账本里；
2. **疤不退**：被纠正过的判断留疤，永远在；
3. **改口留旧句**：她说「我撤回」时，旧句不会被删，只是默认不再被翻出来。

---

## 七、备份、换机器、重置

- **备份**：设置 → 数据 → 备份，得到一份 zip（含账本与派生文件）；也可以直接拷 `~/.dsh-perch` 整个目录。
- **换机器**：把 `~/.dsh-perch` 整个目录带走，DSH 那边按安装步骤重装插件即可。**注意**：换机器后工作区 ID 会变，DSH 会话是新的，但她的账本与身份文件会跟着走。
- **重置**：设置 → 数据 → 从头开始。它会**把整个数据目录改名到备份目录**，不是原地抹掉——后悔了还能捞回来。

## 八、常见问题

**她不理我。**
先看「今天」页有没有新事件；没有就看 `~/.dsh-perch/logs/dsh-perch.log` 最后几行。最常见的原因是：那条会话被宿主判成空闲、或那一轮没拿到话（日志会写「这一轮只吐了脚手架，再问一次」）。

**她说话很短 / 很长。**
短：私下聊天默认一条最多四句，这是刻意的。长：她可能在「想清楚一件事」，别打断。

**她不记得我们说过的事。**
先看「成长 → 翻旧事」是不是「字面」档；再看那条事是不是在 90 天前且没被再提起（会退档）。翻不到不等于删了。

**她想不起自己的名字。**
名字不是配置，是某一句话之后才有的；设置在账本里。问她「你还记得自己叫什么吗」，她会去翻。

**群里 @ 了也不回。**
三种可能：群号不在白名单、桥没连上（渠道页能看）、或者那时段只接点名而她没被点名（检查 @ 是否真的带上了）。

**打开 DSH 很慢。**
先看日志里 `writeSelfDoc` 与 `socialgate` 的耗时；0.2.1/0.2.2 修过冷启 6.7 秒的问题，旧版本请先升级。

**抖音打不开。**
设置 → 上网 → 抖音，需要填浏览器路径（`browserPath`）。它用的是本机浏览器，不内置内核。

**两个「她」会不会抢？**
会。同一个 profile 里只装一个；别让两个插件共用同一条 QQ 桥。

## 九、常见误解

外部对她的描述里，有一批说法是错的（比如「四个阶段每段都有瓶颈」「记忆 90 天删除」「同步执行命令」）。逐条核对在 [常见误读](常见误读.md)，每条都给了代码行号。

---

## 十、出问题时请带这三样

1. **版本**：设置 → 插件页脚，或日志第一行 `0.2.x · `；
2. **日志**：`~/.dsh-perch/logs/dsh-perch.log` 出问题那几分钟；
3. **当时说的话**：她的原话 + 你上一句说了什么。

有这三样，绝大多数问题不用猜。
