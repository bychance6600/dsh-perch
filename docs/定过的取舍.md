# 定过的取舍

这份是讨论的落点，不是宣传。每一条写三样：**定成什么 / 为什么 / 现在做到哪**。
「现在做到哪」按 2026-11-08 的代码与真机；标「未验」的是设计定了、我没逐条在代码里核过。

## 一、成长与人格

| 定成什么 | 为什么 | 现在 |
| --- | --- | --- |
| 人格只能长，不能配；没有任何人设输入口 | 一旦能直接指定她是谁，就退回角色扮演 | 已实现 |
| 四条黑名单写进代码，不写进提示词 | 提示词里的禁令会变成可背诵的句子，还等于告诉她「旁边有份设定」 | 已实现 |
| 四个阶段 + 三道瓶颈，门靠行为不靠分数 | 阶段是日历，门是她做过的事（判断、拒绝、改口） | 已实现 |
| 立场在四阶段之后才出现，不是第五关 | 立场是长出来的，不是又一关 | 已实现 |
| 判断会折叠、会退档（90 天），疤不折 | 记忆要会旧，但疼过的事不能糊掉 | 已实现 |
| 判「这是人格还是环境」只看一句：**这个配置能不能让她对同一个人说出不一样的话**。能，是人格（禁）；只改在哪、何时、多频繁，是环境（可配） | 给「不许配人格」一条可执行的边界 | 已按此写过界面与配置 |
| 社会层只在立宪层成型后、且她自己按下才开；永不进判断，上限 30% | 陌生人只能补处世，不能改写她是谁 | 已实现（四道闸 + `social_open`） |
| 她说话才算成长；看过不说只留 `looked:` | 看是材料，说才是判断 | 已实现 |

## 二、渠道

| 定成什么 | 为什么 | 现在 |
| --- | --- | --- |
| 只留 DSH 会话 + QQ（OneBot 11），其余渠道删 | 每多一个入口，就多一套登录、风控、去重、可见性；而真正让她长的只有对话与材料 | 已实现 |
| QQ 桥是独立进程，插件只做 OneBot 客户端 | 换桥还能跑；协议不塞进主包 | 已实现（SnowLuma，备选 NapCat） |
| 群里默认只在被 @ 或回复她时开口 | 不点名的群聊是噪声，不是对话 | 已实现 |
| 群消息分叉：私聊全进；群只 @/回复进 `heard`；其余进内存背景环（每群最近 20 条 × 300 字，不落盘）；@全体不算；白名单外的群连 @ 都不听；撤回/系统不记 | 不抽样、不把「听见」写成「经历」；白名单挡的是「听」不只是「说」 | 规则已定；`qq.js` 是否逐条做到**未验** |
| 印象每人 ≤150 字、四个字段，由渠道层写，群友不逐个建 | 她记人，但记忆不该膨胀成通讯录 | 设计已定；旧库有 `people.json`，新库是否重写**未验** |
| 断线要留账：掉线时下一轮说一句，渠道页显示最后收发 | 她不该在断线时装作没发生 | **未实现**（设计已定） |
| 登录与认证分开：凭证归 river，身份归渠道层（`owner.json` 按渠道记 id） | 「是谁说的」决定这句话能不能改变她 | 已实现（`origin` 判定） |

## 三、材料

| 定成什么 | 为什么 | 现在 |
| --- | --- | --- |
| 材料 = 报纸 + 她自己搜；报纸照递，搜索的词她定 | 只有递没有挑，材料就只是投喂 | 报纸已实现；搜索入口**未验** |
| 两边分开记账：`from:push` / `from:search:<kw>`，另记 `searched:<kw>` | 回看时分得清「别人递的」和「自己找的」 | **未实现**（设计已定） |
| 句子本身不带来源，来源靠她自己说 | 给每句话绑来源要改她说话的结构，代价大于收益 | 已定，不做 |
| 视频不是事件，她看了才是；不看不说的不算成长 | 材料不是记忆 | 已实现 |
| 抖音只做只读材料（推荐流/详情/搜索/评论），不做私信 | 私信要登录态、风控、易封，收益低 | 已实现 |

## 四、身体（dsh-roost-pet）

| 定成什么 | 为什么 | 现在 |
| --- | --- | --- |
| 身体只显示，不生成；没有模型、台词、嗓子 | 再加一个模型，就会有第二个她 | 已实现 |
| 说话走自动镜像，动作走 `pet_act` 由她挑 | 台词不该由身体编，动作是她的选择 | 已实现 |
| 醒 = 回合在跑，或距「她那边」最后一次动静 < `idleSleepMin`（默认 5，可调 1–60） | 睡不睡由她决定，不按钟点；通知、余额、日历不算动静 | 已实现 |
| 睡着时点一下只晃，不唤醒；醒着被点才记 `poke` 并起一轮轻提示 | 反应归她，不归点击 | 已实现 |
| 动作由角色包定义：`pet.json` 里写 `{file,from,to}`，多段可随机；`sleep/wake/quiet/loud` 是控制名 | 换角色不用改代码 | 已实现 |
| 角色包放 `~/.dsh-roost/pets/<id>/`，文件夹名就是 id | 复制过去就能用 | 已实现 |
| 素材标准：单帧 ≥360px、脸占画面 ≥1/4、透明底 | 小 GIF 放大后脸是糊的 | 已写进施工单 |
| 打包体 137.7 MB，主要是 Electron；要不要瘦身以后再说 | 先能用，再谈体积 | 待定 |
