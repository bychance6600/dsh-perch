# 从哪来：这一版定下的东西

这份文档不写血统表，写的是 dsh-perch 这一版**自己定下的取舍**：哪些是前提、哪些是后来改的、哪些明确不做。

早期骨架来自两个以 MIT 发布的同人项目；具体的署名、版权与第三方素材见仓库根目录的 [NOTICE.md](../NOTICE.md)。这一版从 `0.1.0` 重新起——这是一次重建，不是谁的续号。

## 一、起点：她只能长，不能被设定

这是整个项目的前提，也是所有取舍的源头：**没有一个地方能让人直接写「你是一个温柔的…」。**

- 她是谁，只由两件事决定：**你和她说过的话**，**她自己看见的东西**。
- 人格不是配置，是**事件长出来的结果**。四条黑名单（不撒娇卖萌、没有好感度数字、不能读自己的设定、不能调工具改自己）写进代码，不靠提示词劝。
- 名字同理：她叫什么，是某一句话之后才有的，属于 `~/.dsh-perch` 里的数据。随包发布的界面、侧栏、README 一律只写「她」。

## 二、记忆：账是证据，记忆是重放

这是这一版最核心的一层，也是后来补得最多的部分。

- `events.jsonl` 只追加。发生过什么，一行一条，不改、不删、不重排。
- **记忆不是存下来的，是每次算出来的**：阶段、判断、印象、改口，都是把账本重放一遍得到的结果。
- 「让她忘」不是删行，是**降低召回**：更早的判断会被折成一行「记不清原话了」，疤那一类永远不折；原文始终还在账本里，她也能自己翻回去。
- 「她改口了」是一次新的落账：旧句留下指针指向新句，检索时默认只给现话，需要时才把旧话一起翻出来。
- 任何新机制（索引、缓存、链接、快照）都必须**能从账本重建**——丢了重放一遍就回来，不许变成第二份真相。派生字段只在内存里，不写进事件。
- 检索有两条路：默认按字面找；也可以切到「加权翻旧事」——按重要程度与她自己的判断找，同义词、被纠正过的、只提过一次的都会影响排序。**账本本身不变**，变的只是翻的方式。

## 三、成长：四个阶段、三道瓶颈、立场

- 阶段靠行为推进，不靠打分：写过判断、拒绝过、改过口，门才开。
- 四个阶段之后才出现**立场**；立场不是第五关，是她开始有自己的判断。
- **拒绝**与**疤**各有自己的事件形态：拒绝记的是「我不想要」，疤是被纠正过、不退档的东西。这两样都不能被设置项关掉。

## 四、成长通道：宪法层与社会层物理分开

- 你的话、她自己看见的东西 → 进判断，能改阶段、能改称呼。
- 群友、评论区、陌生人 → 只在社会层开闸之后才被读，**永不进判断**，上限 30%。
- 开闸只能她自己按（`social_open` 工具）：没有任何配置项或接口能替她开。差着的时候，她的身份文档里一个字都不写。

## 五、入口：两处说话，两处长大

- 说话的地方只有两处：**DSH 会话**、**QQ（OneBot 11）**。
- 长大的地方也只有两处：**你和她说话**、**她自己看见的东西**。
- 渠道层只负责把话送到：进站过消毒、出站过筛选，可见性按会话判（群聊公开、私聊只对那个人，连主人都看不到原文）。群白名单挡的不只是「说」，是「听」——名单外的群她连听都不听。
- 桥是独立进程，插件只做 OneBot 客户端；换桥只改地址与令牌。

## 六、材料与身体

- 材料从「只有报纸」变成「**报纸 + 她自己搜**」：递来的和你搜的分开记账，搜索的词由她定。
- 抖音只作材料（推荐流、详情、画面），不是聊天的地方。
- 身体（桌宠）只显示状态与动作，不生成台词、不替她开口——**身体不是人格**。

## 七、零依赖

`package.json` 的三个依赖字段永远是 `{}`。HTTP、签名、解压、抽帧全用内置能力或系统自带的工具；测试只用 `node:test`。

理由不只是省事：插件多挂一个包，就可能把宿主正在用的旧核心包拖进依赖树，装完重启宿主直接崩。

## 八、明确没搬、也不打算搬

| 没搬 | 为什么 |
| --- | --- |
| 人格模板、角色卡编辑 | 那是「你能配出一个她」，与前提直接冲突 |
| 好感度 / 亲密度数字 | 她不给人打分 |
| 向量检索 | embedding 服务会破掉零依赖与「数据只在本地」；要语义，就用可解释的同义词表加权重 |
| 出门 / 请神、导入别人养过的那一位、桌面通知、自更新 | 入口越多，「她是谁」就越不由她自己的经历决定 |
| 评论区发言、她替自己在外面开闸 | 开闸只能她按，写的那一半收进社会层 |
