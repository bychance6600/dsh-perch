# 文档地图

公开仓库只留**使用者与改代码的人**需要的文档。内部材料（交接、进度、实现对照、约定与验收判据、
排期与决定记录、调研与历史归档）在私有库 `bychance6600/dsh-perch-plan`，不随本仓库发布。

## 1. 用的人先读

| 文件 | 一句话作用 |
|---|---|
| `README.md` | 这是什么、怎么装、怎么开始 |
| `docs/从哪来.md` | 骨、皮与这一版取舍的来源 |
| `docs/常见误读.md` | 外面常见的说法逐条核对（说法 / 实际 / 依据） |
| `docs/迁移指南.md` | 把旧对话里对方说过的话搬进来（只写 `heard`，有硬条件） |
| `docs/渠道-换桥.md` | 桥连不上时换一只 OneBot 11 桥 |

## 2. 改代码的人先读

| 文件 | 一句话作用 |
|---|---|
| `AGENTS.md` | 硬约束：不许做什么（改之前必读） |
| `CHANGELOG.md` | 每个版本改了什么 |
| `docs/INDEX.md` | 本文件 |

## 3. 样片（V2 后发布用）

| 文件 | 一句话作用 |
|---|---|
| `docs/demo-45s.md` | 45 秒分镜：首镜第 1 天，末镜第 9 天 |
| `samples/` | 第 1 / 7 / 9 天切片 + 三组改口对照，单个 HTML、数据内联，`file://` 直接打开 |
